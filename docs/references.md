# 公开 storyboard 参考

- [Milkitic/storybrew.Benibotan — WordPanel.cs](https://github.com/Milkitic/storybrew.Benibotan/blob/master/WordPanel.cs)：字块错时进入、缩放与淡入淡出。

- [Damnae/storybrew](https://github.com/Damnae/storybrew)：本机使用的原生脚本引擎与 OSB 动画命令。

本工程参考上述歌词的空间切换和入场节奏，自行实现四角交替、滑入、缓慢漂移和滑出；未复制第三方贴图或场景代码。
